# JavaScript Projects

## Calculator
### Description
Web application built to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.
### Tech stack
<ul>
<li>HTML5 – structure of the app</li>
<li>CSS3 – modern UI styling (neumorphism style)</li>
<li>JavaScript (ES6) – logic and functionality</li>
</ul>

### Preview
Here’s a screenshot of the app:
![Calculator Screenshot](https://github.com/SabriAya/javascript-projects/blob/main/calculator.png?raw=true)
### How to Run the Project Locally:
 1. Clone the repository
git clone https://github.com/SabriAya/javascript-projects.git
 2. Go into the project folder
cd calculator
 3. Open calculator.html in your browser

## Digital Clock
### Description
A modern digital clock web application that dynamically displays the current time in hours, minutes, and seconds.
### Tech stack
<ul>
<li>HTML5 – for structuring the clock layout</li>
<li>CSS3 – for creating the gradient, blur, and glass-like visual style</li>
<li>JavaScript (ES6) – for real-time time updates using the Date() object</li>
</ul>

### How to Run the Project Locally:

 2. Go into the project folder

 3. Open clock.html in your browser
